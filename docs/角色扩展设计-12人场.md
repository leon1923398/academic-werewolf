# 学术狼人杀 · 12 人场角色扩展设计

对标网易官方狼人杀（下称「网易版」）的角色机制，全部改写成软件工程语境的版本。
**所有技能沿用本作的核心设计：出手必须先答题，答错技能作废。** 这一条不改。

---

## 零、先定三条设计原则

**一、只抄机制，不抄名字。**
网易版的角色是真的好用——骑士决斗、守墓人查尸、摄梦人连坐，每一个都能制造"信息差"和"站边压力"。但这些名字搬进高校活动就出戏。所以每个角色都找一个**软件工程里干同一件事的岗位**：验尸的变成查 git log 的，连坐的变成结对编程的，白天决斗的变成架构评审。

**二、新角色必须造出新的话术压力。**
12 人场最容易变成"4 个神各玩各的、4 个民干坐着"。所以这次扩的角色里，有一半是**逼人开口**的：架构评审官要在发言阶段当众点名、CI 哨兵会自己响、冻结管理员能封嘴。**玩家的发言量才是"以辩促思"的落点**，不是答题数量。

**三、每个技能都要能出题，且题目类型不能撞。**
四个技能已经绑死了四类题（规范 / 审查 / 调试 / Bug）。新角色要么复用，要么新增题类。下表里我标了每个角色考哪类，**同一夜不会让一个人连答两题**。

---

## 一、角色总表（12 个新角色）

### 好人阵营 · 神职（对标网易神牌）

| 学术版角色 | 对标网易 | 技能（学术化表述） | 答题 | 答错后果 |
|---|---|---|---|---|
| **测试老兵** | 猎人 | 出局时提交「复现报告」，指名一人带走。若对方是卧底，带走成功 | Bug 识别 | 报告作废，枪哑火 |
| **架构评审官** | 骑士 | 白天发言阶段可发起一次「架构评审对决」，点名一人。被点者是卧底则当场出局并立即入夜；是好人则评审官自己出局 | 代码审查 | 对决不成立，白耗一次机会（不自伤） |
| **实习生** | 白痴 | 被投票出局时翻牌「实习生免责」，免死，但从此刻起**永久失去投票权** | 无需答题 | — |
| **结对伙伴** | 摄梦人 | 每晚与一人结对写代码，该人当晚免疫暗害；但**结对伙伴自己出局时，被结对者随之出局** | 编程规范 | 结对失败，对方不受保护也不连坐 |
| **Git 考古员** | 守墓人 | 每晚查一次 git log，得知**昨天被投票出局那个人**是好人还是卧底 | 调试排错 | 日志被冲掉，当晚无信息 |
| **冻结管理员** | 禁言长老 | 每晚冻结一人，该人白天**不能发言**（仍可投票） | 编程规范 | 冻结失败 |

### 好人阵营 · 特殊（慎用）

| 学术版角色 | 对标网易 | 技能 | 答题 | 备注 |
|---|---|---|---|---|
| **CI 哨兵** | 熊 | 被动：若与你**左右相邻**的座位里有卧底，天亮时系统自动报警（不指认是谁） | 无需答题，但报警当晚需答一题「调试排错」才确认方向 | 报警是真的，但邻座两个里可能是好人 |
| **重构工程师** | 魔术师 | 每晚可对调两名玩家的座位号，当晚所有技能指向随之对调 | 代码审查 | **实现成本最高，暂不进默认板子** |

### 卧底阵营

| 学术版角色 | 对标网易 | 技能 | 答题 | 答错后果 |
|---|---|---|---|---|
| **遗留系统** | 狼王 | 卧底。出局时（非被毒）可发动「技术债引爆」，带走一人 | Bug 识别 | 引爆失败 |
| **零日漏洞** | 白狼王 | 卧底。白天可「公开披露」＝自爆并**同时带走一人** | Bug 识别 | 披露失败，继续发言；**次数照扣** |
| **幽灵提交** | 隐狼 | 卧底。但**代码审核员核验你时，会显示为好人**。你不知道谁是队友 | 无 | 这是全场最阴的一张牌 |
| **影子分支** | 石像鬼 | 卧底。每晚可偷看一人的**具体身份**（不是阵营，是角色名）。但狼队夜里选刀时你参与不了 | 调试排错 | 偷看失败 |

### 身份牌

| 学术版 | 对标网易 | 说明 |
|---|---|---|
| **警长（Merge 权限）** | 警长 + 警徽 | 见第三节，票权 1.5，可决定发言顺序，死时移交或撕毁 |

## 二、三套 12 人板子

### 板子 A ·「预女猎骑」（入门，推荐首次用）

```
好人神职 4：代码审核员 / 豆包 / 测试老兵 / 架构评审官
好人平民 4：普通程序员 ×4
卧底    4：Bug 制造者 ×4
```

**为什么推荐这个**：4 狼全是白板狼，没有狼王没有隐狼，好人靠纯粹的推理和验人就能赢；骑士（架构评审官）给了好人一个"白天主动开会"的出口，节奏不会拖。**第一次开 12 人场就用这套，别贪心。**

### 板子 B ·「预女猎守 + 狼王」（进阶）

```
好人神职 4：代码审核员 / 豆包 / 测试老兵 / 学术监督员
好人平民 4：普通程序员 ×4
卧底    4：Bug 制造者 ×2 / 遗留系统 ×1 / 零日漏洞 ×1
```

难度上来了：两个带人狼让好人不敢乱投、不敢乱开枪。守卫（学术监督员）的"不可连守"在这里变成关键操作——守错人等于送狼一刀。

### 板子 C ·「隐狼局」（高难，给打过两轮的人）

```
好人神职 4：代码审核员 / 豆包 / 测试老兵 / 结对伙伴
好人平民 4：普通程序员 ×4
卧底    4：Bug 制造者 ×2 / 幽灵提交 ×1 / 影子分支 ×1
```

**这套是全场最好玩也最折磨的**：审核员（预言家）验到幽灵提交会看到"好人"，等于这个人的验人成本白花；影子分支每晚偷看一个人的具体身份，狼队信息碾压好人。好人唯一的解法是**靠发言逻辑而不是靠验人**——正好是这个活动想训练的东西。

## 三、警徽：完整规则（对标网易，含落地细节）

警徽是本作唯一的"公开权力"，也是 12 人场能不能撑住的关键。下面按时间顺序写死。

### 3.1 竞选（仅第 1 天）

天亮公布死讯之后、正式发言之前，进入**上警阶段**。

- 主持人逐个问「是否上警」，点座位标记。**上警的人数不限，也可以无人上警**。
- 上警者按座位顺序依次发言，每人 **60 秒**（比正式发言短，因为只是拉票）。
- 上警者发言期间可以**退水**（退出竞选），退水后立刻恢复普通玩家身份，但**退水的人不能投票选警长**。

### 3.2 投票

- **只有没上警的存活玩家有投票权**，上警者（含退水者）一律不投。
- 平票怎么办：**平票则警徽作废（撕警徽）**，不再重投。理由见 3.6。
- 得票最高者当选**警长**，拿到 Merge 权限。

### 3.3 警长的三个权力

| 权力 | 具体规则 |
|---|---|
| **加权票** | 投票时警长的票算 **1.5 票**。落地实现：内部按 2 分制记，普通票 2 分、警长票 3 分，最后除以 2 |
| **定发言序** | 每天发言开始前，警长选择「从几号开始 + 顺时针 / 逆时针」。默认顺时针，警长可改 |
| **归票权** | 平票时，如果警长本人就在平票者之中，**警长直接出局**（网易规则）；否则重投一次，再平则无人出局 |

### 3.4 警徽移交

警长出局时（被投、被刀、被毒、被带走都算），主持人立刻问：

- **移交给场上任意一名存活玩家** → 那个人成为新警长，继承 1.5 票权。
- **撕毁警徽** → 本局从此没有警长，不再重选。

**移交给谁，是这局最好看的一句话。** 因为接收者不一定是好人——警长自己也可能被骗子骗了。

### 3.5 警徽流（口头约定，不需要系统支持）

老玩家会说"警徽流给 7 号"，意思是"我死了之后警徽给 7 号"。这是**口头承诺**，系统不做强制，主持人也不需要记录。它存在的意义是给好人留一条"我死了你听谁的"的信息线索——**这条线本身就是推理的一部分**。

### 3.6 为什么平票就撕警徽

网易版平票是重投。我改成直接作废，理由是 12 人场时间紧：第一天如果卡在选警长上重投两轮，整局要往后拖 10 分钟。而且**"选不出警长"本身就是个信息**——说明场上没有强势带节奏的人，后面投票会更容易散。

## 四、夜晚行动顺序（12 人场完整版）

顺序是硬规则，主持人照着念就行。**加粗的是新增步骤**。

| 序 | 步骤 | 角色 | 备注 |
|---|---|---|---|
| 1 | 设防 / 结对 | 学术监督员 **或 结对伙伴** | 二者不同时上场（看板子） |
| 2 | 冻结 | **冻结管理员** | 如上场 |
| 3 | 睁眼选刀 | Bug 制造者 + 遗留系统 + 零日漏洞 + 幽灵提交 | **影子分支不参与选刀** |
| 4 | 偷看身份 | **影子分支** | 单独睁眼，狼队已闭眼 |
| 5 | 用药 | 豆包 | 每晚只能用一种药，全局各一次 |
| 6 | 核验 | 代码审核员 | 验幽灵提交会显示"好人" |
| 7 | 查尸 | **Git 考古员** | 查的是昨天投票出局者，**不查夜里死的** |

### 白天顺序

```
公布死讯
  → 【第 1 天】上警竞选 → 警长投票 → 产生警长
  → 警长定发言序
  → 轮流发言（架构评审官可发动对决 / 零日漏洞可自爆披露 / 冻结者不能发言）
  → 全员投票（警长 1.5 票）
  → 出局结算（实习生翻牌免责 / 猎人与狼王开枪 / 警徽移交）
  → 判胜负，否则进下一夜
```

## 五、与网易版的规则差异（都是有意的）

| 项 | 网易版 | 本作 | 为什么改 |
|---|---|---|---|
| 警长平票 | 重投 | 直接撕警徽 | 12 人场时间紧，且"选不出"本身是信息 |
| 骑士决斗失败 | 骑士自己出局 | 对决不成立，白耗机会 | 决斗本身要答题，答错就自伤等于双重惩罚，太劝退新人 |
| 实习生翻牌 | 免死 + 失去投票权 | 同网易，**但需答对一道题才生效** | 否则好人白捡一条命，卧底心理落差太大 |
| 熊（CI 哨兵） | 天亮直接咆哮 | 报警后需答题确认方向 | 直接给答案太强，加一道题把它压回"线索"而不是"结论" |
| 隐狼 | 不与狼队睁眼 | 同网易，且**自己也不知道队友** | 更彻底的信息隔离，避免隐性同伙作弊 |
| 所有技能 | 直接生效 | **必须先答题** | 本作核心设计，不动 |

## 六、落地优先级

不是 12 个角色都要一次做完。建议按这个顺序进代码：

**第一批（做板子 A 够用）**
1. 测试老兵（猎人）
2. 架构评审官（骑士）
3. 实习生（白痴）
4. 警徽全套（竞选 / 加权票 / 定序 / 移交 / 撕毁）

**第二批（板子 B）**
5. 遗留系统（狼王）
6. 零日漏洞（白狼王）
7. 学术监督员与结对伙伴并存时的选择逻辑

**第三批（板子 C）**
8. 幽灵提交（隐狼）
9. 影子分支（石像鬼）
10. 结对伙伴（摄梦人）

**第四批（可选）**
11. Git 考古员、冻结管理员、CI 哨兵
12. 重构工程师（实现成本最高，最后做）

## 七、给主持人的一句话

12 人场比 6 人场难的不是规则，是**控场**：六个人你能盯得住每个表情，十二个人你只能靠流程。所以这套设计里所有新机制都是**流程化的**——上警、定序、移交、翻牌，每一步界面都会逼你走完，不给你"凭感觉主持"的空间。

**照流程念，就乱不了。**
